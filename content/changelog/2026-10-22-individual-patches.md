title: Individual patches, no backup mode
date: 2026-10-22

---

Toolkit can read and write single patches on the JD-08 over USB. You don’t restart the synth in backup mode, and you don’t replace its whole memory to change one sound.

The Memory tab shows the JD-08’s 256 patch slots. Drag a patch from your library onto a slot, rearrange slots by dragging, then choose **Save to JD-08**. Toolkit writes only the slots that changed. The JD-08’s own backup files still open in Toolkit when you want the whole memory at once.
